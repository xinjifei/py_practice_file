## boot strap
### 概念
> 一种以反复抽样为基础的统计学技术，在这次的学习里主要是用于模拟‘纯靠运气’的策略生成的sharpe分布
### 实现方法
1. 原始数据准备，数据形式：列表
    - 1.5  将原始列表每个值减去其均值，使均值变为 0
2. 随机抽取原始数据中的数据，输出：float
3. 重复进行抽取，并将结果放入新列表，直到列表长度 == 原始数据列表长度
4. 重复制造新列表，直到列表数量达到特定统计学意义的标准；通常重复 1000 次以上，让运气分布充分展现
## 假设检验
### 概念
> 怎么直到自己的策略是真的厉害还是撞大运，使用这个对比法进行检验
### 实现方法
1. 原始数据准备（在投资测试里面就是收益率列表）
2. 要看‘纯靠运气’策略的收益率，需要先将原始数据的均值变成零
    - 依次将原始数据列表中的数据依此取出减去其均值
3. 算出‘纯靠运气’策略的收益率的Sharpe值的概率分布
    - 对经过 ‘依次将原始数据列表中的数据依此取出减去其均值’的列表进行bootstrap
    - 取bootstrap后的所有新列表（1000个这种数量级一般是）的Sharpe值
    - 获得连续概率分布
    - 3.5  计算 p 值
        - 统计 bootstrap 分布里比「真实值」更极端的样本数量
        - p = 极端样本数 ÷ 总数（1000）
        - p 越小 → 越难用运气解释 → 策略越可能真有效
> 思考:这里的bootstrap分布图的标准差越大 == bootstrap Sharpe不稳定 == 难以区分运气与实力之间的差别
4. 量化sharpe可信度，通过 源数据Sharpe÷bootstrap标准差 得到`偏离距离`
> 思考：量化后的值越高越可信
