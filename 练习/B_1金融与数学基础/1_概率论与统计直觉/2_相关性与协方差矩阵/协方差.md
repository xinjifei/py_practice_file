# 协方差以及相关系数
## 协方差
### 概述
> 和方差一样大部分情况下只作为一个中间步骤，而不能用于直接参考
### 计算步骤
#### 1. 需要两组数据
```python
#这里列表里面的值是原始统计数据
x_list = [x, y ... z]
y_list = [x, y ... z]
```
#### 2. 求每组数据的平均值
#### 3. 将每组的原始数据依此减去其对应的平均值，得到差值列表
```python
Δx_list = [Δx, Δy ... Δz]
Δy_list = [Δx, Δy ... Δz]
```
#### 4. 计算偏差乘积
1. 从差值列表中取出数值，得到数组
```python
Δx_list[Δx]
#以及
Δy_list[Δx]
```
2. 将两者相乘得到偏差值的乘积列表
> 这里就会发现如果数组内两个数据的符号相同则结果为正，反之则为负
#### 5. 求偏差值乘积列表内的值的平均值
- if 数据为样本数据
> 这里的求平均值操作和方差求平均值一样除的不是 n 而是 n - 1  
因为在数学上任何一组数据距离它自己的均值的差值的平方和，永远小于它距离其他任何数值的差值的平方和  
因此根据样本计算的方差一定会小于真实的方差，为了解决这个问题把计算平均值时的分母变小（这个分母就是样本数据列表的长度），经过计算，发现结论：  
*将分母从n变为n-1可以完美的抵消这种误差*  
- if 数据为全部数据  
> 正常求平均值

#### 得到结果（协方差）
### 伪代码

## 相关性系数
### 思考：
> 协方差只能作为计算的一个过程并不具备参考价值，因为他最后计算出来的值会因为原始偏差值大小（量纲）的影响
#### 例：
两组数据计算协方差
```python
#这里为了简化直接用偏差值
a_Δx_list[1, 2, 3]
a_Δy_list[1, 2, 3]

a_Δx_list[10, 20, 30]
a_Δy_list[10, 20, 30]
```
经过计算得出：
- 列表组 a 的协方差为1.33
- 列表组 a 的协方差为13.33

> 两个列表组的相关性看样子都是100%（完全一样）。但是前者却比后者大10倍，这个数字明显不能说明后者两个数组之间的相关性比前者的大10倍

#### 所以就需要一种算法获得绝对的相关性数值，这个数值叫`相关系数`
### 公式
相关性系数 = 协方差 ÷ 原始列表a的标准差 × 原始列表b的标准差

### 最后得出一个-1 ~ +1 的浮点数值，可以直观的看出相关性
