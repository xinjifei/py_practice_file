uv环境总结：
目的：快速的创建完整的开发环境
具体创建：
    1、.gitignore，用于使git仓库忽略某些文件（比如.venv，API密钥等）
    2、.python-version，用于声明项目所需的python版本
    3、pyproject.toml，项目的配置文件+说明书，别人拿到这个项目，只需要 uv sync 就可以对齐所有配置
    4、README.md，专门给人阅读的说明书，也可以让ai读

使用：
    uv init
        初始化当前路径下的uv环境（这一步会创建上面说的几个文件）
    uv run *文件名*
        使用当前路径下的uv环境运行
    uv sync
        对齐当前路径下uv环境的配置
    uv add
        下载库
    uv pip list
        显示当前路径下uv环境中所安装的库
    uv tree
        显示当前路径下uv环境中库的依赖树
