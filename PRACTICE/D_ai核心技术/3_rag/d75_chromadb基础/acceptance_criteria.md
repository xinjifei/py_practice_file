- 阶段四「AI 核心技术」，分组「RAG 检索增强生成」的第 1/6 天——这是 RAG 整条链路的入口。

- **归你（必须长在脑子里）**：语义搜索与关键词搜索差在哪、为什么；向量数据库存的是什么；一次"存入"和一次"查询"各自发生了什么；什么时候该上向量库、什么时候不该。
- **可外包（概念知道、实现交给 AI）**：ChromaDB 的具体 API 签名、参数名、SentenceTransformer 的模型名与调用写法。忘了可以查，不必背。
