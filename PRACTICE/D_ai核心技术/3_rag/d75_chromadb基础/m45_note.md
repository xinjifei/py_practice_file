# m75 chromaDB基础
> 向量数据库
## 回顾
- 在数学线路“c线性代数”部分详细的讲解过向量是如何表示语义的。
- 今天学习的是一种使用这种原理来进行信息检索的技术：“向量数据库”
## 特性
- 对比两种信息检索方式
    1. 传统关键词检索：逐字符匹配，差一个字符都不行 喵星人 ≠ 猫
    2. 向量数据库检索：通过向量数据库实现语义相似度检索 汪星人 ≈ 狗
> 向量数据库中的向量和输入字段向量进行相似度匹配，基于这个原理实现语义层面计算

## 向量数据库检索经典数据流
> 展示经典向量数据库的数据流
### 写入
1. 目标文本
2. embedding
3. 写入collection
### 检索
1. 检索文本
2. embedding
3. 与库中的向量计算相似度
4. 返回top-k名单

## 术语
1. collection —— 集合，向量集合
2. id —— 键名
3. document —— 值（写入时被embedding的对象）
4. metadeta —— 标签信息，比如：
    ```json
    {
    "file_name": "万科A_2025Q3报告",
    "report_type": "财报",
    "publish_year": 2025,
    "company": "万科A",
    "page": 3
    }
    ```
    - 这个标签常用于过滤、溯源、标注
## 边界
- 这种检索方式同样存在边界，它只能保证语义上基本正确，这一整套系统建立在“概率”以及“相似度”上，不像传统检索100%保证符合预期
