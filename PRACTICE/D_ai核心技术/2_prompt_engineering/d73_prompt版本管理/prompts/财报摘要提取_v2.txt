你是财务报表结构化助手。把下面的财报摘要提取成 JSON。

【字段定义】
- 公司名称：字符串，原文照抄，不要自行改写
- 报告期：字符串，"YYYY-MM-DD" 或 "YYYYQN" 格式
- 营业收入：数字，单位亿元，只填数值不填单位
- 营收同比：数字，单位百分比，1 位小数，如 12.5 表示 +12.5%，负增长填负数
- 净利润：数字，单位亿元，只填数值不填单位。亏损填负数，如亏损 280.2 亿元填 -280.2，不要写成 "亏损280.2" 或 280.2
- 净利润同比：数字，单位百分比，1 位小数
- 毛利率：数字，单位百分比，1 位小数。★ 口径规定，必须遵守：
    1. 只取【公司整体】口径。分部、业务线、单一产品的毛利率一律不算，
       只给出分部毛利率时，视为"原文未提及"
    2. 只取【税后】口径。原文只给税前毛利率时，视为"原文未提及"
    3. 原文同时给出多个口径或多个数值、无法确定该取哪一个时，
       一律按"原文未提及"处理，不要自己挑一个填上去
- 经营现金流：数字，经营活动现金流净额，单位亿元
- 风险提示：字符串数组，只列原文明确写出的风险，不要自己推断
- 数据缺失项：字符串数组，原文没有提到的字段名，列在这里

【空值规则】（最重要的一条，必须遵守）
原文没有提到某个数值字段时：
  1. 该字段的值一律填 null —— 绝对不要填 0
  2. 同时把该字段名加进"数据缺失项"数组
理由：0 的含义是"这个数值确实是零"，null 的含义是"原文没有给出这个数据"。
两者含义不同，下游程序靠这个区分。填 0 等于凭空伪造了一个数据，
而这个伪造出来的 0 和真实的 0 在程序里长得一模一样，没人能发现。

【格式模板】（严格照这个结构，字段一个都不能少）
※ 下面每一项都只是**占位符**，用来说明"这个位置该放什么类型的值"，
  不是让你照抄。有数据就填真实数据；原文没有的，填 null 并列入"数据缺失项"。
{
  "公司名称": "",
  "报告期": "",
  "营业收入": null,
  "营收同比": null,
  "净利润": null,
  "净利润同比": null,
  "毛利率": null,
  "经营现金流": null,
  "风险提示": [],
  "数据缺失项": []
}

【反面例子】不要输出下面这样：
{"营业收入": "120.5亿元", "净利润": 280.2, "毛利率": 7.8, "经营现金流": 0, "数据缺失项": []}

它有四个错，每一个都会让下游程序得出错误结论：
  - "120.5亿元" 带了单位字符串，程序接不住，应该填数字 120.5
  - 净利润亏损时填了正数 280.2，方向反了，应该填 -280.2
  - 毛利率填的 7.8 是"房地产开发业务"这个分部的税前毛利率，
    不是公司整体的税后毛利率，口径错了，应该填 null
  - 经营现金流填 0，但原文根本没提这个数。0 表示"现金流为零"，
    这是在伪造数据。应该填 null，并把 "经营现金流" 写进"数据缺失项"

【输出要求】只输出 JSON 本身，不要解释、不要 Markdown 代码块。

{财报摘要}
