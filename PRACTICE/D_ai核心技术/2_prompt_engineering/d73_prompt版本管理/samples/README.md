# samples —— 练习用数据

这些是**喂给 prompt 模板的数据**，不是模板本身。模板在 `../prompts/`，占位符原样留着。

## 为什么单独放一个目录

- 模板改一次，所有样本都受益；样本换一批，模板不用动。
- 做 A/B 对比时，**两个版本的 prompt 必须读同一组样本**（今天的要求）。样本独立成文件，两版都读它，才能保证"变的只有 prompt 这一个变量"。
- 数据文件以后要加要删，和模板的改动历史分开，`git log` 干净。

## 数据来源

三份财报摘要都取自公开披露的 2025 年三季报，数据经网络检索整理，**是练习样本，不保证与公告原文逐字一致**——真做数据管道时要以交易所公告为准。

- 宁德时代（300750）：2025 年三季报，2025-10-20 披露
- 贵州茅台（600519）：2025 年三季报，2025-10-29 披露
- 万科A（000002）：2025 年三季报，2025-10-30 披露

## ★ 万科那份是故意留的"脏数据"

它**没有经营活动现金流的数据**（原文里没有），而且毛利率只给了"房地产开发业务"的分部口径、不是公司整体。

这是刻意的：模板里的 `数据缺失项` 字段，就是为这种情况准备的。检验两件事——

1. 模型会不会**如实留空并报进 `数据缺失项`**，还是编一个数出来；
2. 你的校验代码会不会因为空值/缺字段而崩。

一份干净的样本测不出这两样。真数据永远是脏的。
