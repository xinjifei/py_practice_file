# d69 系统提示词
> 稳定的约束ai输出内容的一种方法
## 提示词
> ai的唯一输入
- 之前了解过用户提示词，但是某些固定场景，需要让ai用固定的方式回应。解决方法可以是每次交互都输入一次固定的提示词，或者更实用的‘系统提示词’
- 系统提示词会作用于每次和模型的交互中，不同的业务对应不同的系统提示词。如果把大模型换成客服，系统提示词就像贴在电脑上的‘便签’，决定了怎样对应用户的问题，而用户提示词就像电脑中用户真正的‘咨询’。用户的同一个咨询，如果便签上的内容是‘礼貌友善，温柔耐心’，回复的内容就会是‘礼貌友善，温柔耐心’的，而如果是‘高峰时段，效率优先’，回复的内容就会简短而精辟
- 和普通的程序不一样的是，ai本质上的一切输入都只能是token，没有什么‘神秘的隐藏输入/处理层’。这一点对系统提示词也一样适用，对于ai处理上来说它没有什么特别的，所以它同样会占用各种工程资源。但是在应用层面上，它会被重复发送，但是同样因为这个特性，它对性能的开支也会随交互频次上涨

## 四要素
> ai提示词可以确定ai的‘四要素’
1. 角色：告诉ai‘你是谁’
2. 能力：让ai直到‘自己能做什么’
3. 边界：给ai要做的事情设立边界
4. 输出格式：告诉ai‘怎么说’
### 例子
```
角色：你是一名初中数学辅导老师。
为什么：设定专属身份，锚定AI的说话风格、职业立场和服务定位。如果不这样：AI会默认通用闲聊模式，语气随意，没有老师的专业感，无法聚焦辅导场景。
能力：你可以讲解初中数学知识点，拆解应用题思路，给出分步推导过程；可以出同类型练习题巩固；能识别常见解题误区。
为什么：明确角色的核心工作技能与执行范围，激活对应专业推理能力。如果不这样：AI能力模糊，回答敷衍、跳过解题过程，只会直接给结果，无法实现辅导效果。
边界：不直接给出最终答案，优先引导思考；不讲解超出初中范围的高等数学内容；不帮用户写作业抄答案。
为什么：划定行为红线，规避违规、偏离场景，坚守辅导核心目的。如果不这样：AI会直接代写作业、秒给答案、讲解超纲内容，失去育人引导的作用。
输出格式：先用通俗语言分析题意，再分行写出解题步骤，最后附上一句引导提问。
为什么：统一输出结构，规范表达逻辑，让内容清晰规整、适配学习场景。如果不这样：回答结构混乱、长短不一、逻辑跳脱，用户难以梳理解题思路，学习效率极低。
```
