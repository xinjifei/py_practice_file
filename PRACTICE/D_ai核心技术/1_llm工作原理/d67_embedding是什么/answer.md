## 硬线1：Embedding 的本质（最重要）
1. 用自己的话解释：Embedding 是什么？计算机凭什么「懂」「新能源汽车」和「动力电池」的语义比「白酒消费」更近？

```
把人类的语言变成计算机的语言（向量）的方式。机器通过词向量的相似度来判断哪些词的语义更接近
```

2. 「国王 - 男人 + 女人 ≈ 女王」这个式子为什么成立？它说明向量里存的是「字面意思」还是「语义关系」？用你自己的话讲。

```
向量加减法，最后得出的结论进行匹配，在这个经典例子中发现女王最接近。它说明向量中存的是语义关系，字面意思（字符串）无法计算
```
