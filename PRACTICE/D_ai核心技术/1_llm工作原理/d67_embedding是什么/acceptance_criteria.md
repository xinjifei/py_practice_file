# 第 67 天验收标准

## 体系定位
- 所处阶段：阶段四「AI 核心技术」——这个阶段培养的是「AI 协作能力」的底层：不是会用 API，而是懂模型内部由哪些可理解的概念构成。
- 今天在「LLM 工作原理」section 里的位置：第 2/4 天。昨天（66）学了 Token（模型「看」的最小单位），今天学 Embedding（模型「懂」语义的方式），后面 68 是采样参数、69 是 prompt 结构。
- 与目标的关系：Embedding 的「向量 = 语义坐标、距离 = 相似度」这条直觉，是**技术判断力**的一块——以后判断「RAG 检索 / 向量数据库 / 相似度匹配」靠不靠谱，靠的是这条直觉，而不是记住 sentence-transformers 的 API。

## AI 分界线
- **归你（必须长在脑子里）**：
  - Embedding 的直觉：文字 → 高维向量，向量之间的距离 = 语义相似度。
  - 「国王 - 男人 + 女人 ≈ 女王」为什么成立：向量里存的是语义关系，不是字面。
  - 判断力：什么场景该用 embedding 检索，什么场景它不适用；看到相似度数字能判断合不合理。
- **可外包（概念要知道、实现交给 AI）**：
  - sentence-transformers 的具体调用、选哪个模型。
  - 余弦相似度 / PCA / t-SNE 的具体实现和参数——知道「都是把向量距离 / 降维的工具」即可。
