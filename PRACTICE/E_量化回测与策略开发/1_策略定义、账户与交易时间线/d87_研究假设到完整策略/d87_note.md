# 研究假设到完整策略
> 策略产生的第一步

## 基础概念
- 研究假设回答“what”以及“why”，它解释有什么假设，以及为什么这个假设成立，而不是如何实现交易闭环。比如有一个假设
    - 连续三天下跌之后，股票可能具有正向的短期超额收益，因为市场可能存在短期过度反应
- 完整的策略则是回答“how”，它把研究假设落地到交易上面，但是它不直接回答为什么要这么设计。比如它需要能够回答
    1. 交易对象：研究哪只股票，还是整个股票市场
    2. 信息时点：第三天下跌结束后，什么时候才能确认信号
    3. 入场规则：第四天开盘买入，还是收盘买入
    4. 退出规则：持有一天、三天，还是反弹 5%就卖
    5. 仓位管理：每次投入全部资金，还是只投入10%
    6. 交易约束：是否考虑手续费、滑点、停牌，以及不能成交的情况

只有研究假设没有策略无法落地回测，只有策略没有研究假设则没法明确自己验证/证伪了什么

## 策略的四个概念

如果按照之前的理解，策略就是一个算法根据指标生成信号中的算法，实际上策略需要覆盖交易闭环的每一个角落，可以分为四块：
1. 指标：历史记录得出的金融指标，比如sma、ema等
2. 信号：算法在通过处理“指标”后作出的判断，比如买、卖
3. 交易：
    1. 订单：交易意图，不等于交易成功
    2. 成交：交易结果
4. 持仓：成交后持有的状态。持有后的价格波动影响持仓市值

所以只有信号无法构成整体的策略

## 回测
> 回测说明了特定场景下策略的表现，只要它得出的结论可以说明“策略——特定场景下策略的表现”的关系，这个回测就是有价值的，无关乎结果正负

因此得到一个结论：
1. 回测结果只能说明策略在特定场景下的表现，而未来总是会产生新的变量，因此回测能赚钱≠未来能赚钱。当然这不是说它得出的结论就没有价值，回测结论与它未来的表现没有绝对关系，不是说他们没有相关性。但是回测的结论往往具有这种常见的误导性
    - 举几个变量的例子：
    1. 历史金融数据
    2. 策略规则
    3. 账户模型
    4. 评价标准
