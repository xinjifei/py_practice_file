# Blocklin 挖床训练地图 — 逐步搭建教程

## 第 0 步：创建世界

1. 打开 Minecraft 基岩版
2. 点击 **游戏** → **新建** → **创建新世界**
3. 在创建世界页面：
   - **游戏模式**：创造
   - **难度**：和平（避免干扰）
   - 往下滑，找到 **作弊**：**开启**
   - **实验性玩法**：全部开启（确保 `/structure` 命令可用）
4. 点击 **创建**

---

## 第 1 步：获取命令方块

在聊天框输入（按 `/` 或 T 打开聊天）：

```
/give @s command_block
```

这会给你一个命令方块。放在地上，再按相同方法多拿几个备用（总共需要 16 个）。

---

## 第 2 步：搭建床 + 外壳

### 2.1 放床

选一块平坦地面，放一张床。记住床头坐标。

站在床旁边，聊天框输入：
```
/chat
```
然后看屏幕左上角，记下坐标，比如 `(100, 64, 100)`。

> **小提示**：建议用一个比较开阔的坐标，比如 x=1000, y=64, z=1000，这样方便后续计算 20 格距离。

### 2.2 包内层（混凝土）

用任意颜色混凝土，把床 **完全包住**（上下前后左右共 6 面）。混凝土和床之间不要留空隙。

> 举例：如果床在 (100,64,100) 和 (101,64,100)，混凝土的范围大约是 (99~102, 63~65, 99~102) 这样一个长方体盒子。

### 2.3 包外层（木板）

在混凝土外面，再包一层木板。同样是完全包裹 6 面。

> 现在床的截面是这样的：**木板外壳 → 混凝土外壳 → 床**

### 2.4 确认

站在外面，确认看不到混凝土和床，只看得到木板外壳。

---

## 第 3 步：保存结构

### 3.1 确定结构范围

站在外壳的一角（最西北下角），记下坐标 `<x1> <y1> <z1>`。

站到对角（最东南上角），记下坐标 `<x2> <y2> <z2>`。

> 结构要包含整个床+混凝土+木板。比如木板外壳从 (98,62,98) 到 (103,66,103)，你就用这两个坐标。

### 3.2 执行保存命令

在聊天框输入（替换成你的实际坐标）：
```
/structure save bed_shell 4 -63 4 -4 -58 -5 false memory false
```

看到 "Structure 'bed_shell' saved" 就成功了。

### 3.3 记录结构起点坐标

**等下加载结构时用的是北西下角坐标**，也就是 x1/y1/z1 中较小的那个。比如上面例子的 `98 62 98`。记下来，这是后面的 `<struct_x> <struct_y> <struct_z>`。

---

## 第 4 步：确定其他坐标

### 4.1 出生点坐标

站在床旁边，往一个方向走 **20 格**，记下这里的坐标。这是 `<spawn_x> <spawn_y> <spawn_z>`。

> 建议选平坦地面，确保从出生点能看到床。用 `/tp @p <x> <y> <z>` 测试是否站在正确位置。

### 4.2 床方块坐标

记下床 **床头** 的坐标（一般是枕头那边）。这是 `<bed_x> <bed_y> <bed_z>`。

> C1 命令会检测这个位置是否还有床。你破坏床后这个位置变成空气，C1 就检测到了。

---

## 第 5 步：创建计分板

在聊天框依次输入这三条（只需一次）：

```
/scoreboard objectives add timer dummy "计时"
/scoreboard objectives add best dummy "最快记录"
/scoreboard objectives add state dummy "状态"
```

初始化最佳记录：
```
/scoreboard players set #best best 0
```

---

## 第 6 步：设置常加载区域

确保你离命令方块很远的时候它们还在运行：

```
/tickingarea add circle ~~~ 4 bed_train
```

这会在你当前位置创建一个半径 4 区块的常加载区域。**建议站在命令方块摆放区域执行这条命令**。

---

## 第 7 步：放置命令方块

### 7.1 先理解布局

我们需要 4 条"链"，每条链的方块箭头首尾相接：

```
组 A（启动链）：     [脉冲] → [连锁] → [连锁] → [连锁]
                        按钮放这里

组 B（计时器）：     [循环]

组 C（检测&重置链）：[循环] → [连锁] → [连锁] → [连锁] → [连锁] → [连锁] → [连锁] → [连锁] → [连锁] → [连锁]

组 D（记录显示）：   [循环]
```

每条链之间不要挨在一起，各留 2-3 格间距，方便调试。

### 7.2 放置组 A（启动链）

1. 在地上放 4 个命令方块，排成一行（东西方向）
2. 确保每个方块的箭头都指向下一个方块（箭头朝东）
3. 第一个方块旁边放一个 **按钮**（石质按钮即可）

**如何设置箭头方向**：放置命令方块时，你站的位置决定了箭头方向。箭头指向你面对的方向。或者放好后潜行+右键点击方块侧面来改变朝向。

### 7.3 放置组 B（计时器）

单独放一个命令方块在组 A 旁边（不用和 A 连在一起）。

### 7.4 放置组 C（检测&重置链）

1. 放 10 个命令方块排成一行，箭头首尾相接
2. 链条比较长，确保每个箭头都准确指向下一个方块

### 7.5 放置组 D（记录显示）

单独放一个命令方块，可以和组 B 挨着。

### 7.6 用图理解整体布局

```
俯视图：

  组A: [脉冲]→[连锁]→[连锁]→[连锁]   ← 按钮在旁边
  组B: [循环]
  组C: [循环]→[连锁]→[连锁]→[连锁]→[连锁]→[连锁]→[连锁]→[连锁]→[连锁]→[连锁]
  组D: [循环]
```

---

## 第 8 步：配置组 A — 启动链

右键点击每个命令方块，填入以下内容。

> **替换规则**：把 `<spawn_x> <spawn_y> <spawn_z>` 换成你第 4.1 步记的出生点坐标，把 `<bed_x> <bed_y> <bed_z>` 换成第 4.2 步记的床头坐标。

### A1（第一个 — 脉冲）

| 设置项 | 值 |
|--------|-----|
| 方块类型 | **脉冲** |
| 条件 | **无条件** |
| 红石 | **需要红石** |

命令：
```
/tp @p <spawn_x> <spawn_y> <spawn_z> facing <bed_x> <bed_y> <bed_z>
```

然后在这个方块侧面放一个 **按钮**。

### A2（第二个 — 连锁）

| 设置项 | 值 |
|--------|-----|
| 方块类型 | **连锁** |
| 条件 | **有条件的** |
| 红石 | **保持开启** |

命令：
```
/scoreboard players set @p timer 0
```

### A3（第三个 — 连锁）

| 设置项 | 值 |
|--------|-----|
| 方块类型 | **连锁** |
| 条件 | **有条件的** |
| 红石 | **保持开启** |

命令：
```
/scoreboard players set @p state 1
```

### A4（第四个 — 连锁）

| 设置项 | 值 |
|--------|-----|
| 方块类型 | **连锁** |
| 条件 | **有条件的** |
| 红石 | **保持开启** |

命令：
```
/tellraw @p {"rawtext":[{"text":"§a▶ 开始计时！最快记录: "},{"score":{"name":"#best","objective":"best"}},{"text":" ticks"}]}
```

> **注意**：如果你想让按钮只在待机状态有效（防止计时中误触），把 A1 改成：
> ```
> /tp @p[scores={state=0}] <spawn_x> <spawn_y> <spawn_z> facing <bed_x> <bed_y> <bed_z>
> ```
> 这样只有 state=0（待机）时才能传送。

## 第 10 步：配置组 C — 检测 & 重置链

> 把 `<bed_x> <bed_y> <bed_z>` 换成床头坐标
> 把 `<struct_x> <struct_y> <struct_z>` 换成第 3.3 步记的结构起点坐标
> 把 `<spawn_x> <spawn_y> <spawn_z>` 换成出生点坐标

### C1（第一个 — 循环）

| 设置项 | 值 |
|--------|-----|
| 方块类型 | 循环 |
| 条件 | 无条件 |
| 红石 | 保持开启 |

命令：
```
/execute as @a[scores={state=1}] at @s unless block <bed_x> <bed_y> <bed_z> bed run scoreboard players set @s state 2
```

### C2（第二个 — 连锁）

| 设置项 | 值 |
|--------|-----|
| 方块类型 | 连锁 |
| 条件 | **有条件的** |
| 红石 | 保持开启 |

命令：
```
/structure load bed_shell <struct_x> <struct_y> <struct_z>
```

### C3（第三个 — 连锁）

| 设置项 | 值 |
|--------|-----|
| 方块类型 | 连锁 |
| 条件 | 有条件的 |
| 红石 | 保持开启 |

命令：
```

```

### C4（第四个 — 连锁）

| 设置项 | 值 |
|--------|-----|
| 方块类型 | 连锁 |
| 条件 | 无条件 |
| 红石 | 保持开启 |

命令：
```
/tellraw @a {"rawtext":[{"text":"§e⏱ 本次用时: "},{"score":{"name":"#time","objective":"timer"}},{"text":" ticks"}]}
```

### C5（第五个 — 连锁）

| 设置项 | 值 |
|--------|-----|
| 方块类型 | 连锁 |
| 条件 | 无条件 |
| 红石 | 保持开启 |

命令：
```

### C6（第六个 — 连锁）

## 第 12 步：测试

1. 站到按钮旁边
2. 按按钮 → 你应该被传送到 20 格外，面向床
3. 聊天栏显示 "▶ 开始计时！最快记录: 0 ticks"
4. 跑向床，挖开木板外壳（外层），再挖开混凝土（内层）
5. 把床破坏
6. 观察：
   - 床+外壳立即恢复
   - 聊天栏显示 "⏱ 本次用时: XXX ticks"
   - 第一次破坏显示 "★ 首次记录！★"
   - 你被传送回出生点
   - actionbar 显示 "最快记录: XXX ticks"
7. 再按按钮，再跑一次（比上次快一点）
8. 观察是否显示 "★ 新纪录！★"

---

## 第 13 步：切换到生存模式训练

确认一切正常后：

```
/gamemode survival
```

然后你就可以：
- 按按钮 → 跑 → 挖 → 破坏床 → 自动重置 → 按按钮 → 循环训练

## 常见问题排查

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 按钮没反应 | state 不是 0 | 在聊天框输入 `/scoreboard players set @p state 0` |
| 破坏床后没重置 | C1 检测坐标不对 | 确认 C1 里的坐标确实是床的坐标 |
| 结构加载不出来 | 结构没保存或坐标错了 | 重新执行第 3 步，确认结构名称是 `bed_shell` |
| 外壳恢复不完整 | 结构保存范围太小 | 扩大保存范围（比外壳多 1 格边距） |
| 命令方块不运行 | 没设置常加载区域 | 站到命令方块旁执行第 6 步 |
| 行动栏没显示 | 组 D 没配置 | 确认 D1 是 循环+无条件+保持开启 |

---

## 进阶：显示秒而非 ticks

如果你想让聊天栏显示"秒"而非"ticks"（20 ticks = 1 秒），可以在 C3 和 C4 之间加两个命令方块。不过这会增加总数到 18 个，操作也更复杂。先用 ticks 跑顺了再说。
