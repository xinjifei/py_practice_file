# 量化 + AI 自学仓库

> 一个持续更新的个人学习仓库：从 Python 与数据处理出发，逐步进入量化研究、人工智能与策略回测。

## 项目介绍

我用这个仓库保存学习过程中产生的代码、练习、笔记和数据处理脚本。它记录的是一套我自己摸索的面向量化金融与 AI 的自学路径。

仓库的重点不只是“学过什么”，还包括如何把一个主题从概念理解推进到可运行的代码，再用笔记和skill验收检查自己是否真的理解。

## 我的学习方法

每个主题通常按下面的闭环推进：

1. 先明确当天要解决的核心问题和范围。
2. 理解概念及其适用边界，而不是只记 API 或结论。
3. 用独立练习把概念落到代码或实际研究场景中。
4. 用自己的话写笔记，并按验收标准检查理解是否完整。
5. 根据练习结果修正下一步的学习重点。

AI 可以协助查资料、实现和检查；研究问题、规则设定与结果解释由我负责。

## 使用方法

### 首次使用

项目使用 Python 3.10+，依赖由 [uv](https://docs.astral.sh/uv/) 管理：

```bash
git clone <repository-url>
cd py_practice_file
uv sync
```

从项目根目录运行脚本时，使用：

```bash
uv run python <脚本路径>
```

部分练习目录有独立的项目配置；进入该目录后，按其中的 `README.md` 或 `pyproject.toml` 操作。

### 浏览学习材料

- 从 `PRACTICE/` 开始：按阶段进入对应主题，再查看当天或当前小节的练习目录。
- 从 `practice_data_source/` 查找行情数据、日线数据和拉取脚本。
- 从 `use/` 查找日常工具和命令记录。

## 历史材料

少数练习目录中的 `.git_local` 用于保留当时的局部 Git 历史；它们是学习过程的历史材料，日常使用基本上用不到。
